Architecture & delivery flow

Single-user Next.js MVP: browser-first state today, Docker-shaped runtime, Jenkins-gated immutable-image promotion.

Runtime today
  • Browser talks to the Next.js UI.
  • Application data remains in client localStorage.
  • Docker Compose serves the production-shaped app on port 3000.
Delivery contract
  • Feature branch / PR enters Jenkins gates.
  • Lint, typecheck, build, Compose validation, and Docker smoke test.
  • Promote the same immutable commit-SHA image; rollback by SHA.
Not deployed here
  • No Kubernetes profile or cluster is part of the current system.
  • PostgreSQL is an optional educational Compose service.
  • Prisma + server-side persistence remain a dashed future path.
